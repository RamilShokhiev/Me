## Featured Projects

### Machine Learning-Based Financial Asset Price Forecasting

Capstone decision-support MVP for short-term forecasting across BTC, ETH, TSLA, and AAPL.

- Built multi-horizon T+1, T+3, and T+7 prediction models with XGBoost.
- Engineered leakage-safe technical indicators including RSI, EMA, MACD, Bollinger Bands, and ATR.
- Exposed predictions through FastAPI endpoints and connected them to a React Native/Expo mobile app.
- Deployed with AWS EC2 and PostgreSQL/RDS, with evaluation through Balanced Accuracy, AUC, Sharpe ratio, and win-rate.

Repository: [StockAI](https://github.com/RamilShokhiev/StockAI)

### Bank Customer Churn Early-Warning System

AI retention system for identifying high-risk banking customers before churn.

- Built a churn prediction pipeline on 10,000 banking profiles with a 20.4% baseline churn rate.
- Used SMOTE and Gradient Boosting to prioritize churn recall over misleading accuracy.
- Improved recall from 49% to about 66% with ROC-AUC around 0.86.
- Delivered a Streamlit dashboard with customer-level churn probability, risk segmentation, and retention action protocols.

Repository: [Bank Customer Churn Early-Warning System](https://github.com/RamilShokhiev/Bank-Customer-Churn-Early-Warning-System)

### Intelligent Root Cause and Urgency Triage Platform

Full-stack AI platform for customer ticket triage and SLA routing.

- Developed a multi-task TensorFlow/Keras network to predict root-cause family and urgency level from 28k+ tickets.
- Compared LSTM, BiLSTM, and CNN architectures and selected a custom CNN triage model.
- Reached 87.8% root-cause accuracy and 67.8% urgency accuracy.
- Built a FastAPI inference backend with a React/Tailwind dashboard for live triage and confidence visualization.

Repository: [Intelligent Root Cause and Urgency Triage](https://github.com/RamilShokhiev/Intelligent-Root-Cause---Urgency-Triage)

### Behavioral Customer Segmentation Dashboard

Marketing analytics system for customer behavior clustering and campaign planning.

- Built an end-to-end segmentation pipeline with Scikit-learn and K-Means.
- Clustered 2,012 retail customer records into 5 behavioral groups.
- Engineered spending diversity, web intensity, and purchase-channel preference features.
- Delivered a Streamlit and Plotly dashboard for customer cluster assignment and campaign recommendations.

Repository: [Behavioral Customer Segmentation for Marketing Strategy Optimization](https://github.com/RamilShokhiev/Behavioral-Customer-Segmentation-for-Marketing-Strategy-Optimization)
